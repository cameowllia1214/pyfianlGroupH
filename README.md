# pyfianl

臺北市咖啡廳推薦系統
Python 資料分析與機器學習期末專題
作者：傅彩華、陳熏鎂、劉心語、陳雨函

專案簡介
本系統為一可解釋之人工智慧決策支援系統，針對有意前往臺北市咖啡廳的使用者，提供個人化的推薦服務。使用者可依據自身需求（行政區、設施條件、價格區間、營業時段）進行篩選，系統將透過加權評分模型與多元線性回歸演算法輸出最符合需求的推薦結果，並附上可解釋的推薦理由。
功能說明
依行政區、設施條件（插座、WiFi、時間限制）、價格區間及營業時段進行多條件篩選
依使用者需求計算各咖啡廳之配適分數並排序，輸出前十名推薦結果
以自然語言說明推薦原因
根據使用者對第一輪推薦結果的喜好排序，利用多元線性回歸演算法進行第二輪個人化推薦
提供 Google Maps 連結供使用者進一步查看店家詳細資訊

資料來源
資料涵蓋臺北市 12 個行政區共 720 間咖啡廳
資料欄位包含：Google 評分、距捷運站距離、插座、WiFi、時間限制、價格區間、營業時間等
資料為特定時間點蒐集之靜態資料，無法即時反映店家營業狀態之變動
需使用 Google 帳號建立 API 後，才可用程式蒐集資料

系統限制
第二輪推薦模型訓練資料僅有 5 筆，可能產生過度擬合，預測結果僅能作為偏好估計
部分店家的 WiFi 與插座欄位為空值，系統將其視為不符合條件而排除，可能遺漏潛在優質選項
條件設定過於嚴苛時，系統可能回傳極少甚至零筆結果

其他注意事項
本專案部分程式碼原為本地環境開發，其中涉及開發者個人資訊的路徑已統一以代稱（如「儲存路徑」）替換，使用前請依據實際環境自行調整相關路徑設定。
原始碼中部分片段含有套件安裝指令與掛載雲端硬碟的相關程式碼，請依據當前環境評估是否保留。
